# Курсовое проектирование

_Целью_ выполнения курсового проекта является применение на практике знаний, умений и навыков, полученных в ходе изучения дисциплины.
В состав курсового проекта входят:

- пояснительная записка;
- графическая часть;
- работающее программное средство (установочный пакет);
- презентация для защиты работы.

Вопросы, которые должны быть рассмотрены при выполнении курсового проекта, и соответствующая им структура расчетно-пояснительной записки включают следующее:

- **введение**: обзор литературных источников по проблематике моделирования и оптимизации проектных решений, **_цель и задачи_** курсового проектирования, **_перечень сред_** выполнения курсового проекта;
- **постановка задачи оптимизации**: задание к курсовому проекту, а также необходимые пояснения, схемы и т.д., уточняющие постановку задачи;
- **построение базовой аналитической модели**: описание математической модели для решения задачи оптимизации;
- **обоснование вычислительной процедуры**: обоснование выбора математических методов (2 метода) для решения задачи оптимизации;
- **решение задачи оптимизации**: подробное описание хода и результатов решения задачи (проект в среде Visual Studio, MS Excel\MathCad\MatLab\SPSS\Statistica); клиент-серверное приложение должно содержать элементы и средства защиты информации, проекта.
- **анализ базовой аналитической модели на чувствительность**: анализ чувствительности результатов решения к изменению параметров задачи;
- **заключение**: основные результаты решения поставленной задачи, выявленные возможности улучшения полученных результатов;
- **список использованных источников**: источники, использовавшиеся при выполнении курсового проекта;
- **приложения**: схемы функциональности приложения; схема классов приложения; результаты решения задач, рассматривавшихся в курсовом проекте, полученные с использованием программных сред.

Для оформления пояснительной записки и приложений используйте рекомендации, описанные в Методические рекомендации по дипломному проектированию для студентов специальности 1-40 05 01 Информационные системы и технологии / разраб.: О. И. Наранович. — Барановичи : РИО БарГУ, 2016. — 44 с.
