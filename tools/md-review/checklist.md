# Markdown Review Checklist

## Structure and Organization
- [ ] Document has a clear title and logical section hierarchy
- [ ] Headings follow proper markdown hierarchy (h1 → h2 → h3, no skipping levels)
- [ ] Table of contents is present if document is long (>1000 words)

## Content Quality
- [ ] All statements are factually accurate and verifiable
- [ ] Information is complete and sufficient for the target audience
- [ ] Examples are clear, relevant, and working
- [ ] Technical terms are properly explained or linked

## Formatting and Style
- [ ] Code blocks have proper language tags for syntax highlighting
- [ ] Links are working and properly formatted
- [ ] Lists (ordered/unordered) are used consistently
- [ ] Tables are properly formatted and aligned
- [ ] Images have alt text and are referenced correctly

## Language and Grammar
- [ ] No spelling or grammar errors
- [ ] Consistent tense and voice throughout
- [ ] Clear and concise writing (no unnecessary verbosity)
- [ ] Technical accuracy in terminology

## Markdown Best Practices
- [ ] No HTML tags where markdown syntax would work
- [ ] Proper use of emphasis (*italic*, **bold**)
- [ ] Blockquotes used appropriately
- [ ] Line breaks and spacing follow conventions
- [ ] File ends with a newline character
